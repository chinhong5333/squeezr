Compress JPEG photos without uploading

Re-encode JPEG and JPG photos with MozJPEG at quality 80. Processing stays in a Web Worker on your device, and the original is kept when a same-size result would not be smaller.

What the JPEG compressor does

Squeezr decodes the source image into pixels and sends those pixels to a MozJPEG encoder running through WebAssembly. The output quality is fixed at 80 so there is no ambiguous slider to tune for every file. JPEG stays JPEG unless you explicitly turn on WebP output.

Because the image is re-encoded from pixels, the result is intended as a smaller delivery copy rather than an archival master. Keep the source file if camera metadata, an embedded colour profile, or exact byte-for-byte provenance matters.

How to compress a JPEG or JPG

  1. Add one or more .jpg or .jpeg files by drop, file picker, or clipboard paste.
  2. Optionally resize the dimensions or enable WebP for a different output format.
  3. Compress, compare the preview, and download one result or the complete ZIP.

JPG and JPEG are the same format

.jpg and .jpeg are two filename extensions for the same image format. Squeezr accepts both. Standard JPEG output uses the .jpg extension, while the original filename is retained when the keep-original safeguard applies.

JPEG, PNG, or WebP?

JPEG is usually the practical choice for photographs when broad compatibility and a familiar editing format matter. Use PNG for sharp interface graphics and transparency. Try WebP when the smallest web-delivery file matters more than keeping the original format.

Privacy and safeguards

The file is not posted to an API. Decode, resize, encode, comparison, and ZIP creation all happen locally. The worker handles one file at a time, rejects sources above 40 megapixels, and keeps the original when compression would increase the size and resize is off.

Compression is irreversible. Keep the original photograph and use the preview before publishing or deleting the source.

JPEG compression questions

Will a JPEG lose quality?

Yes. JPEG compression is lossy. Quality 80 is intended to reduce size while keeping ordinary viewing differences small, but fine texture, repeated saves, and aggressive cropping can expose artefacts. Inspect the preview at the size that matters to you.

Why did Squeezr keep my original?

The source was already smaller than or equal to the re-encoded result. When resize is off, returning the source avoids a larger download with no benefit.

Are photos sent anywhere?

No. Read how local processing works, including which app assets load over the network before the compressor can operate offline.
