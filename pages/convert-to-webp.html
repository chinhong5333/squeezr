Convert images to WebP in your browser

Turn PNG or JPEG files into WebP at quality 80 without uploading them. The main Squeezr compressor lets you enable WebP, resize, and inspect every result before downloading.

What changes when WebP is enabled

Squeezr decodes each PNG or JPEG into browser pixel data and sends that data to the libwebp encoder running through WebAssembly. Output quality is fixed at 80, the file extension changes to .webp, and dimensions remain the same unless you turn on resize.

WebP is a delivery format rather than a replacement for an editable master. Keep the original source when you may need its camera metadata, original compression settings, or compatibility with older software.

How to convert an image to WebP

  1. Open the main compressor, add PNG, JPG, or JPEG files, and enable WebP output.
  2. Optionally select a resize percentage to reduce both dimensions and file size.
  3. Compress, compare the original and WebP result, then download one file or a ZIP.

When WebP is useful

WebP is useful for web photographs, textured graphics, and transparent assets where a smaller delivery file matters. It can outperform PNG on photographic or gradient content and often competes well with JPEG while retaining an alpha channel for transparent pixels.

Keep PNG output for source graphics that depend on a familiar lossless container. Keep JPEG output when compatibility with established photo workflows matters more than the smallest web file.

Privacy and offline use

The image is never uploaded to a conversion service. The browser initially downloads the application and codec assets; compression then runs locally in a Web Worker. The progressive web app precaches those assets so the tool is designed to work without a network connection after they are available.

Use the preview for important transparency and gradient edges, and keep the original file. Squeezr is an experimental personal tool rather than an archival pipeline.

WebP conversion questions

Does WebP change the dimensions?

Not by default. Dimensions change only when Resize is enabled. The selected percentage preserves aspect ratio and never upscales the image.

Can I convert a transparent PNG?

The worker passes RGBA pixel data to the WebP encoder, including transparent pixels. Inspect the before-and-after preview when soft alpha edges are important.

Why did the tool keep my original?

When resize is off, the keep-original safeguard applies if the WebP output would be larger than the source. If you requested a resize, the resized result is returned because the dimension change itself was requested.
